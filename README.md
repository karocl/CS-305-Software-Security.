# CS-305 Software Security

## Artemis Financial – Secure Software Project

This repository contains my Artemis Financial Practices for Secure Software Report, completed for CS-305 at Southern New Hampshire University.

## Project Reflection

**1. Client and software requirements**

Artemis Financial is a financial consulting company that wanted to improve the security of its software application. The company needed to protect sensitive information and make sure its application could communicate securely. My task was to identify security concerns and apply improvements to the existing software.

**2. Identifying vulnerabilities and the importance of secure coding**

I used OWASP Dependency-Check to examine the project's dependencies and identify potential security vulnerabilities. I learned that secure coding is important because it helps protect customer information, reduces security risks, and builds trust in a company.

**3. Challenges during the vulnerability assessment**

The most challenging part was working with Maven and Dependency-Check. I encountered configuration issues and had to troubleshoot them before completing the build. This experience helped me better understand how security tools work and why reviewing their reports is important.

**4. Increasing security layers**

I added security measures such as SHA-256 hashing, a self-signed certificate, and HTTPS communication. In future projects, I would use tools like OWASP Dependency-Check, vulnerability databases, and secure coding guidelines to evaluate risks and decide which security improvements are needed.

**5. Testing functionality and security**

After making changes, I tested the application to confirm that it was working through HTTPS. I also ran Maven and Dependency-Check to review the build and identify reported vulnerabilities. These tests helped me verify the functionality of my changes and identify security concerns that still needed attention.

**6. Helpful resources and tools**

I used Eclipse, Maven, Java, OWASP Dependency-Check, and Java keytool. These tools helped me understand dependency management, certificates, encryption-related security concepts, and secure software development. I expect to use these skills in future projects.

**7. Work to show future employers**

I would show employers my Artemis Financial security report because it demonstrates my experience reviewing software vulnerabilities, configuring secure communication, and testing a Java application. It also shows my ability to troubleshoot technical problems and document my work.
